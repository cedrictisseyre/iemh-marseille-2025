# Projet : Site Ligue 1

Ce projet a pour objectif de créer un site web dédié à la Ligue 1. Le site permettra de consulter :

- Le classement actualisé de la Ligue 1
- La liste des différentes équipes
- Les résultats des matchs
- Les joueurs de chaque équipe
- D'autres informations utiles sur la saison en cours

L'utilisateur pourra naviguer facilement entre les équipes, voir les statistiques des joueurs, suivre les résultats et accéder à toutes les données importantes du championnat.

Ce projet vise à offrir une plateforme claire et interactive pour tous les passionnés de football et de Ligue 1.
