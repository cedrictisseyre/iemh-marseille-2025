# Projet Emploi du Temps - Mastère IHME

Ce projet est une application web permettant de gérer et d’afficher l’emploi du temps du Mastère IHME.

## Fonctionnalités
- Affichage de l’emploi du temps par jour et par horaire
- Liste des matières, professeurs, salles, horaires et jours
- Accès rapide aux différentes données

## Installation
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/cedrictisseyre/iemh-marseille-2025.git
   ```
2. Placer les fichiers sur un serveur web supportant PHP et MySQL
3. Configurer la base de données dans le fichier `connexion.php`

## Prérequis
- PHP >= 7.0
- MySQL/MariaDB
- Serveur web (Apache, Nginx…)

## Utilisation
Accéder à l’URL du projet via un navigateur pour consulter l’emploi du temps et les listes associées.
